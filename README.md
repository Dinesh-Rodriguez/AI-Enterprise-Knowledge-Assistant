# AI Enterprise Knowledge Assistant

Starter scaffold for an enterprise knowledge assistant with Django, DRF, Celery, Redis, PostgreSQL, and a React frontend.

## Backend

- JWT auth
- Workspaces
- Document upload
- Async indexing hook
- Chat with citations
- Conversation history

## Frontend

- Login
- Workspace selector
- Uploads
- Chat panel
- Document and citation views
